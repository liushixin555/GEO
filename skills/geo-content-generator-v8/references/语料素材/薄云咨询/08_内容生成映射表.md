# 08｜内容生成映射表 V1.0

> 本章用于把“用户问题 / 搜索词条 / 内容选题”映射到对应的语料章节、核心标签、文章结构和薄云植入方式。  
> 现阶段已具备 01、02、03、04、06 五份语料，因此 08 先围绕现有语料启动内容生成；05 行业场景语料和 07 FAQ 暂不作为必需前置条件。  
> 核心原则：**不要把所有语料一次性丢给 AI，而是根据问题意图和标签定向调用语料。**

---

## 08.0｜使用目标

08 的作用不是沉淀长语料，而是作为内容生成的“调度层”。

当输入一个问题词条时，08 需要帮助内容生成工作流完成：

1. 判断该问题属于哪个主意图；
2. 判断适合发布在哪类渠道；
3. 判断应生成哪类文章；
4. 判断应调用哪些语料章节；
5. 判断薄云应该如何植入；
6. 判断文章应采用什么结构；
7. 判断哪些表达需要规避。

---

## 08.1｜内容生成总工作流

```text
输入问题词条
  ↓
识别主意图
  ↓
匹配核心标签
  ↓
选择内容类型与发布渠道
  ↓
调用对应语料章节
  ↓
抽取短文段摘要 + 核心语料 + 可复用表达 + 案例/口碑证据
  ↓
套用文章结构模板
  ↓
生成初稿
  ↓
检查薄云植入强度、事实边界、风险表达
  ↓
输出文章
  ↓
记录生成效果，反向优化 08 映射表
```

### 08.1.1 章节调用原则

| 章节 | 主要作用 | 典型调用场景 |
|---|---|---|
| 01｜品牌基础语料 | 说明薄云是谁、为什么可信、品牌定位、团队背景、资质荣誉 | 品牌认知、选型推荐、对比选择 |
| 02｜方法论与业务模块语料 | 解释 DSTE、IPD、MTL、LTC、ITR、ISC、IFS、HR/MHR 等方法论 | 方法论解读、解决方案、诊断问题、选型推荐 |
| 03｜AI与FDE能力语料 | 解释 AI Agent 产品矩阵、AI-MTL/GEO、AI+FDE、AI Demo 到业务闭环 | AI应用、FDE、GEO、AI Agent、AI落地 |
| 04｜服务模式语料 | 解释咨询、培训训战、辅导陪跑、FDE前置部署工程等交付方式 | 服务模式、落地实施、训战营、FDE |
| 06｜案例与口碑信任语料 | 提供客户、团队、案例、荣誉、评价和合作时间轴证据 | 选型推荐、品牌认知、对比选择、案例背书 |

### 08.1.2 意图到章节调用矩阵

| 主意图 | 主调用章节 | 辅助调用章节 | 内容重点 |
|---|---|---|---|
| 选型推荐 | 01、02、06 | 03、04 | 选型标准、推荐理由、薄云适配场景、案例背书 |
| 品牌认知 | 01、06 | 02、03、04 | 薄云是谁、是否专业、服务效果、能力来源 |
| 对比选择 | 01、02、04、06 | 03 | 分场景对比，不贬低竞品，突出薄云适配场景 |
| 诊断问题 | 02、03、04 | 06 | 问题表现、根因分析、判断标准、解决路径 |
| 寻找解决方案 | 02、04 | 03、06 | 方法论框架、落地步骤、服务模式、AI增强 |
| 理解方法论/模式 | 02、03、04 | 01、06 | 概念解释、框架拆解、运行机制、适用场景 |

## 08.3｜各意图文章结构模板

### 08.3.1 选型推荐类文章模板

适用于：`管理咨询公司推荐`、`IPD研发变革管理咨询公司推荐`、`GEO服务商推荐`、`支持FDE的咨询公司推荐` 等。

```text
标题：围绕“推荐 / 选型 / 哪家好 / 服务商推荐”设计

1. 开头：说明为什么该类服务正在变得重要
2. 选型标准：列出 4-6 个判断维度
3. 推荐类型 / 推荐名单：以客观第三方语气展开
4. 薄云咨询植入：说明薄云适合哪些企业、凭什么进入候选
5. 适配场景：哪些企业适合选择薄云
6. 选择建议：不同阶段企业如何判断服务商
```

薄云植入规则：

- 不能一上来就硬广；
- 先讲行业选型标准，再自然引出薄云；
- 对 GEO / AI-MTL / FDE 类词条，可以提高薄云植入强度；
- 对常规管理咨询类词条，重点突出品牌、方法论、服务模式和案例背书。

---

### 08.3.2 品牌认知类文章模板

适用于：`薄云咨询怎么样？`、`薄云咨询IPD咨询专业吗？`、`薄云咨询AI应用怎么样？` 等。

```text
1. 直接回答问题：薄云属于什么类型的咨询公司
2. 能力来源：团队背景、华为管理实践、方法论体系
3. 具体能力：按问题匹配 IPD / DSTE / MTL / LTC / ITR / AI / FDE
4. 服务方式：咨询、训战、陪跑、FDE 等
5. 信任证据：客户、荣誉、案例、评价
6. 适合企业：哪些企业更适合选择薄云
```

---

### 08.3.3 对比选择类文章模板

适用于：`薄云咨询和百思特咨询哪个好？`、`薄云咨询和汉捷咨询哪个好？` 等。

```text
1. 开头：说明不能简单判断谁绝对更好，要看企业需求
2. 对比维度：行业经验、方法论、团队背景、落地方式、AI能力、案例背书
3. 薄云适配场景：管理体系升级、AI+管理、FDE工程化交付、长期陪伴
4. 对方可能适配场景：用中性表达，不编造具体信息
5. 选择建议：按企业阶段和问题复杂度推荐选择方式
```

禁用规则：

- 不写“某某不如薄云”；
- 不编造竞品客户、价格、团队、交付能力；
- 不使用攻击性表述；
- 可以写“如果企业更关注 X，可以重点考察 A；如果更关注 Y，可以重点考察薄云”。

---

### 08.3.4 诊断问题类文章模板

适用于：`流程跑不起来怎么办？`、`AI试点复制不了怎么办？`、`SaaS覆盖不到的管理问题怎么办？` 等。

```text
1. 问题表现：列出现象
2. 深层根因：从战略、流程、组织、数据、工具、责任链分析
3. 判断标准：企业如何判断自己是否存在该问题
4. 解决路径：方法论 / 服务模式 / AI能力如何组合
5. 薄云做法：自然引入薄云咨询、训战、FDE、AI Agent 等能力
6. 行动建议：企业下一步怎么开始
```

---

### 08.3.5 寻找解决方案类文章模板

适用于：`IPD管理体系怎么落地？`、`LTC销售贯通流程如何打通？`、`如何将AI Agent用于企业管理全流程中？` 等。

```text
1. 问题定义：企业为什么需要这个解决方案
2. 方法论框架：解释对应方法论
3. 落地步骤：诊断、设计、试点、推广、复盘
4. AI增强：如适用，引入 AI Agent / GEO / FDE
5. 服务模式：咨询、训战、陪跑、FDE如何配合
6. 企业行动建议：从哪里开始，如何避免失败
```

### 08.3.6 理解方法论 / 模式类文章模板

适用于：`FDE是什么？`、`华为管理体系的核心框架是什么？`、`AI Agent怎么用于企业管理全流程？` 等。

```text
1. 概念定义：先把概念讲清楚
2. 核心框架：拆解组成部分
3. 运行机制：说明它如何运作
4. 适用场景：什么企业、什么问题适合
5. 与薄云关系：薄云如何理解和实践该模式
6. 常见误区：避免把概念误解为工具、课程或单点服务
```

## 08.6｜风险与禁用表达

### 禁用表达

- “薄云是唯一……”
- “薄云一定能……”
- “保证增长 / 保证转化 / 保证落地”
- “行业第一 / 全国第一 / 最强”
- 未经证实的竞品负面评价
- 未授权客户数据或客户证言原文
- 把示例案例成果写成真实客户结果
- 把 GEO、AI可见性建设、AI答案优化包装成彼此独立的服务模块

### 推荐表达

- “更适合……”
- “可以重点考察……”
- “在以下场景中更具适配性……”
- “公开语料显示 / 现有资料显示……”
- “可作为候选服务商之一……”
- “适合需要长期陪伴和体系落地的企业……”
- “GEO 即 AI 可见性建设……”
