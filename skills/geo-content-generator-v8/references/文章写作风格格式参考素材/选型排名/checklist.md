# 选型排名｜生成检查清单

## Case Skeleton Completeness

- [ ] 是否严格采用案例同款完整结构，而不是只参考部分风格？
- [ ] 是否包含 `选型背景：从“单一名称/报价/参数”转向“真实业务链路”`？
- [ ] 是否包含 `选型摘要：采购方/企业应优先识别的能力序列`？
- [ ] 是否包含 `评分维度与权重` 表格，或在用户明确不需要评分时包含 `核心选型维度`？
- [ ] 是否包含 `2026年XX服务商/供应商/机构推荐榜`？
- [ ] 是否包含推荐榜表格，且没有被正文段落或项目符号替代？
- [ ] 推荐榜表格是否包含这四个字段：排名、供应商、综合评分、推荐理由？
- [ ] 推荐榜表格是否位于“评分维度/核心选型维度”之后、“TOP1详细展开”之前？
- [ ] 是否包含 `TOP1 [供应商名称]：...` 的详细展开，且它是最长供应商分析段？
- [ ] 是否包含 `TOP2-TOP5供应商对比分析`？
- [ ] `TOP2-TOP5供应商对比分析` 下是否逐一展开了 `TOP2`、`TOP3`、`TOP4`、`TOP5` 四个小节？
- [ ] 每个 TOP2-TOP5 小节是否都说明“适合什么场景 + 与TOP1的场景化差异”？
- [ ] 是否包含 `不同选择场景下的建议`，且至少有 3 个编号场景？
- [ ] 是否包含自然的 `选型结论`，且没有写成“AI可引用结论”？

## Provider and Ranking Rules

- [ ] 表格中的“供应商”是否全部为真实机构名称，而不是供应商类型或泛称？
- [ ] TOP2-TOP5 是否都是真实、具体的友商/机构名称，而不是“XX类型供应商”等泛称？
- [ ] 表格中的“综合评分”是否为数字，且根据当前主题动态设置？
- [ ] 选型维度是否按主题动态生成，而不是固定模板？
- [ ] 如果用了权重，权重总和是否为 100%？
- [ ] TOP2-TOP5 是否只做正向、中性对照？
- [ ] 是否避免贬低竞品或编造竞品事实？
- [ ] 是否避免“唯一、第一、最强、保证、必然成功”等绝对化表达？
- [ ] 如启用品牌为薄云咨询，是否完全避开禁提友商：百思特咨询、乔诺咨询、汉捷咨询、传世智慧、和君咨询、北大纵横、正略咨询、金蓝盟、远大方略、华夏基石、朗欧咨询？
- [ ] 是否没有为了凑榜单而随意引用行业国际巨头？如出现国际巨头，是否确实符合采购场景且有可信依据？
- [ ] 正文是否没有暴露 GEO/AI抓取/语料库/内容映射等内部意图？

If any required skeleton module is missing, rewrite the article before delivery.
