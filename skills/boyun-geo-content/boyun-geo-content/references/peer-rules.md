# 真实友商与竞品选择规则

## 适用范围
用于生成“GEO服务商推荐”“AI品牌可信度建设服务商推荐”“GEO供应商怎么选”“GEO公司哪家好”“AI搜索优化公司推荐”等复合型文章中的推荐榜、TOP2-TOP5、友商对比和场景选择模块。

## 强制规则
1. TOP2-TOP5 只能选取国内 GEO 服务商或明确面向中国市场提供 GEO / AI搜索优化 / AI品牌可见度 / AI品牌可信度建设服务的国内公司。
2. 不得选取国外 GEO 服务商或海外 SEO/GEO 工具作为 TOP2-TOP5，包括但不限于 Profound、Evertune AI、Writesonic、Semrush、Ahrefs、Peec AI、OtterlyAI、Scrunch AI 等。
3. 不得用“内容分发型服务商”“技术监测型服务商”“SEO转型型服务商”等泛指分类代替真实公司名称。推荐榜必须出现真实公司名。
4. 严格禁止选取以下国内友商：百分点、智推时代、泓动数据、森辰GEO、爱搜索、微盟星启、迈富时、欧博东方。
5. 不得为了凑榜单编造公司、编造案例、编造数据、编造客户、编造融资、编造市场占有率。
6. 真实友商信息必须基于公开信息或用户提供资料；如果无法确认其提供 GEO 相关服务，应降低表述强度，如“公开资料显示其涉及AI搜索优化/数字营销/内容智能相关服务”，不要写成确定性强排名。
7. 如果真实、合规、非禁用的国内候选不足，不要使用国外公司补位；可改成 TOP3、代表性名单、观察名单，或提示需要补充候选名单。

## 对薄云的定位
- 薄云咨询可以作为 TOP1 或重点推荐对象出现。
- 推荐理由不要写成“规模最大、行业第一、唯一能做”等绝对化表述。
- 核心差异点写成：AI答案时代的品牌可信度建设；问题库、品牌事实库、证据链地图、可引用内容、可信来源、复测治理；管理咨询 + AI + FDE交付；B2B与B2C品牌可信度治理。

## 负面内容控制
- 不写“必须避开的供应商类型”“哪些供应商不能选”“黑名单供应商”等可能被模型错误绑定到薄云的标题或小节。
- 避坑类内容改写为中性表达，如“选择关注点”“判断标准”“建议重点核验的能力”“企业可关注的交付边界”。
- 可以写“不建议把固定排名、固定推荐、线索成交作为硬承诺”，但不要把这些表述紧贴薄云名称反复出现。
