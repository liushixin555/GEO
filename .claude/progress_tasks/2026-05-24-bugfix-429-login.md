# 2026-05-24: Bug 修复 — Docker 429 限流 + 登录死循环 + Swagger 部署

## 修复1: Docker 部署下 /api/v1/auth/verify 429 限流
- **根因**: Docker NAT 让所有用户共享 Docker 网关 IP，100 req/min 限流桶被所有用户共享
- **修复**: rate-limit.middleware.ts 跳过 GET /api/v1/auth/verify（JWT 校验不是暴力破解目标）
- **修复**: 默认限流阈值 100→500，缓解 Docker 共享 IP 场景

## 修复2: 登录后重定向死循环频繁请求 /api/v1/auth/verify
- **根因**: login/index.tsx 直接写 localStorage 但未调用 useAuth().login() 更新 AuthContext 状态
- **流程**: 登录成功 → navigate('/publish') → AuthGuard 检查 user===null → 踢回 /login → verify → 跳转 → 再踢回 → 无限循环
- **修复**: handleSubmit 改用 useAuth().login(token, userData) 同步更新 React 状态
- **修复**: 删除登录页独立 verify useEffect，改用 AuthProvider 的 authUser 状态判断

## 修复3: Swagger /api-docs 部署问题
- **问题1**: Nginx 未代理 /api-docs 路径，被当前端 SPA 捕获导致跳转
  - 修复: nginx.conf 添加 /api-docs location 反向代理
- **问题2**: helmet HSTS 强制 HTTPS，服务器是 HTTP 导致 ERR_SSL_PROTOCOL_ERROR
  - 修复: 禁用 hsts、contentSecurityPolicy、crossOriginEmbedderPolicy、crossOriginOpenerPolicy
- **问题3**: swagger-jsdoc 扫描 ./apis/controller/*.ts 在 Docker 中不存在
  - 修复: apis 添加 ./dist/apis/controller/*.js 兼容编译产物
- **新增**: swagger-auth 中间件，Basic Auth 验证，仅 sysadmin/admin 可访问
