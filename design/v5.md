# GEO 自动化运营系统 UI/UX 看板方案 v5

对应原型文件：`GEO自动化运营系统_看板原型_v5.html`

## 1. 设计目标

本方案优先覆盖唯一超级管理员和运营用户的完整工作台。系统定位为内部 GEO 自动化运营控制台，不做营销首页。只读用户后续主要访问客户开放的检测看板、报告和数据结果，不单独设计复杂后台。

V5 的核心体验目标是：

1. 以客户项目为运营单位管理全流程。
2. 以关键词为内容生成和检测迭代的核心对象。
3. 每日检测按单项目呈现，重点关注露出率、TOP3 推率、舆情风险和信源引用。
4. 运营动作都能从待办、关键词、内容、发布、检测页面形成闭环。

## 2. 全局布局

| 区域 | 说明 |
| :--- | :--- |
| 左侧导航 | 固定一级导航，进入总览、今日待办、客户项目、项目概览、关键词运营、内容生成、发布管理、每日检测、复盘报告、资产库、系统管理。 |
| 顶部栏 | 仅展示当前页面标题与说明。V5 已移除全局搜索框、负责人筛选和时间筛选，避免干扰各页面自己的业务筛选。 |
| 主内容区 | 按页面承载看板、表格、弹窗、在线编辑器和项目级检测仪表盘。 |

## 3. 一级导航

| 页面 | 角色 | 主要用途 |
| :--- | :--- | :--- |
| 总览 | 管理员、运营用户 | 项目级整体运营概况，不展示关键词级检测细节。 |
| 今日待办 | 管理员、运营用户 | 聚合人工确认事项和处理入口。 |
| 客户项目 | 管理员、运营用户 | 项目列表与新建项目唯一入口。 |
| 项目概览 | 管理员、运营用户 | 单项目运营情况，包含资料、待办、趋势、风险和历史操作。 |
| 关键词运营 | 管理员、运营用户 | 资料上传、业务分析、关键词提取、关键词诊断和关键词库管理。 |
| 内容生成 | 管理员、运营用户 | 审批建议生成方案、生成文章、在线编辑或上传成品文章。 |
| 发布管理 | 管理员、运营用户 | 管理发布任务、计划发布时间、发布平台和状态。 |
| 每日检测 | 管理员、运营用户 | 单项目 GEO 监测仪表盘。 |
| 复盘报告 | 管理员、运营用户 | 周报、月报、阶段复盘管理。 |
| 资产库 | 管理员、运营用户 | 按资产分类和项目沉淀资料、关键词、内容、截图和报告。 |
| 系统管理 | 超级管理员 | 账号、权限、接口、客户授权和系统配置。 |

## 4. 客户项目

客户项目页是唯一的新建项目入口，其他页面不出现“新建项目”交互。

**新建项目弹窗**

| 字段 | 类型 | 要求 |
| :--- | :--- | :--- |
| 客户名称 | 文本 | 必填 |
| 客户联系方式 | 文本 | 必填 |
| 项目负责人 | 下拉 | 必填 |
| 所在行业 | 文本 | 可选 |
| 客户现有资料 | 上传 | 可选，上传后与项目强绑定 |

**项目列表字段**

客户、行业、负责人、综合露出率、综合 TOP3 推率、待办、风险、最近检测、状态。

## 5. 项目概览

项目概览是单项目运营面板，顶部通过下拉菜单切换项目。

**核心模块**

| 模块 | 说明 |
| :--- | :--- |
| 项目指标 | 今日待办、低效关键词、综合露出率、综合 TOP3 推率、风险预计、待发布内容。 |
| 项目资料列表 | 展示该项目池内所有资料文件，包括上传资料和平台生成资料。 |
| 项目状态管理 | 可手动调整项目为运营中、暂停或终止；该入口不突出，因使用频率较低。 |
| 历史人工操作记录 | 折叠模块记录人工确认、发布调整、权限变更等动作，避免占用主页面空间。 |
| 每日检测结果 | 按关键词呈现露出率、TOP3 推率和风险，不展示竞品占位和建议动作。 |
| 推送趋势 | 按天展示露出率和 TOP3 推率变化。 |
| 今日待办 | 复用总览的任务卡交互，支持确认关键词、查看原因、确认发布、调整排期。 |
| 迭代工作流 | 展示低效关键词到内容生成、发布、再检测的闭环。 |
| 风险预警 | 展示当前项目的新增负面、未露出、竞品压制等风险。 |

## 6. 关键词运营

关键词运营流程：

`上传客户资料 → 分析客户业务 → 提取业务关键词 → 诊断哪些关键词客户的用户喜欢提问 → 输出高频关键词清单 → 人工确认后续开展优化工作的关键词`

**页面模块**

| 模块 | 说明 |
| :--- | :--- |
| 项目切换 | 下拉切换项目。 |
| 客户资料清单 | 展示与项目绑定的上传资料和平台生成资料；支持上传资料。 |
| 客户业务输入 | 可手动输入业务描述，用于补充系统分析。 |
| 业务关键词提取 | 基于资料和业务输入提取关键词。 |
| 关键词诊断输入 | 可手动输入想诊断的关键词。 |
| 关键词方案 | 诊断后输出高频关键词清单，用户确认后同步到内容生成。 |
| 项目关键词库 | 以项目区分呈现关键词库，支持手动添加关键词。 |

## 7. 内容生成

V5 将原“内容迭代”统一改为“内容生成”。自动迭代回流本质上从内容生成开始，因此不再单独拆出内容迭代页。

**建议生成方案清单**

字段包括：关键词、项目、文章类型、发布平台、建议形成时间、来源、草稿、审批。

每一条建议同时提供两个动作：

| 动作 | 说明 |
| :--- | :--- |
| 查看草稿 | 草稿在审批前可查看和修改。 |
| 审批并生成 | 审批动作放在清单中完成。 |

**在线编辑**

| 模块 | 说明 |
| :--- | :--- |
| 标题栏 | “文章在线编辑”。 |
| 手动上传成品文章 | 支持直接上传本地完成稿。 |
| 保存草稿 | 编辑区右上角只保留保存草稿，不放审批按钮。 |
| 编辑器 | 支持在线编辑文章正文。 |
| 参考资料 | 展示品牌资料、内容生成参考文库、禁用表达等。 |

## 8. 发布管理

发布页管理发布任务，不再只叫发布计划。

**发布任务清单字段**

| 字段 | 说明 |
| :--- | :--- |
| 内容标题 | 待发布内容标题。 |
| 关键词 | 内容关联关键词。 |
| 项目 | 所属客户项目。 |
| 发布平台 | 第三方媒体、官网、自媒体。 |
| 内容类型 | 榜单排名、方法论讲解、案例分析、行业洞察、对比测评、客户证言、FAQ问答、实操指南。 |
| 计划发布时间 | 待计划状态可为空。 |
| 发布状态 | 待计划、待定时发布、已发布、发布失败。 |
| 操作 | 每个任务都有“编辑计划”，用于调整发布时间等参数。 |

**新建发布计划弹窗**

点击右上角“新建发布计划”后打开弹窗，支持手动导入发布计划。

弹窗字段包括：项目、发布平台、内容类型、计划发布时间、待发布内容勾选清单。

## 9. 每日检测

每日检测是单项目页面，通过项目下拉切换不同客户项目。

**顶部 KPI**

| 指标 | 说明 |
| :--- | :--- |
| 核心关键词数 | 当前项目监测关键词池数量。 |
| 问答检测总量 | 当日跨平台检测总次数。 |
| 品牌露出总量 | 当日品牌被 AI 回答提及的总量。 |
| TOP3 总量 | 当日进入 TOP3 推荐位置的总量。 |
| 舆情统计 | 显示今日是否有新增负面内容。 |
| 低效关键词 | 需要迭代优化的关键词数量。 |

V5 不再统计信源占比，不再展示 TOP1 或首推口径，统一使用 TOP3。

**推送趋势**

原“维度诊断”改为“推送趋势”。

图表为按日展示的双柱趋势图，每天一组：

| 柱 | 指标 |
| :--- | :--- |
| 露出率 | 当日项目全平台露出率。 |
| TOP3 推率 | 当日项目全平台 TOP3 推率。 |

支持选择时间区间后即时生成。

**核心指标表现**

展示：

1. 所有关键词全平台露出率。
2. 所有关键词全平台 TOP3 推率。
3. DeepSeek 露出率 / TOP3 推率。
4. 豆包露出率 / TOP3 推率。
5. Kimi 露出率 / TOP3 推率。
6. 元宝露出率 / TOP3 推率。

**关键词检测明细**

字段包括：

关键词、综合露出率、DeepSeek露出率、豆包露出率、Kimi露出率、元宝露出率、千问露出率、综合 TOP3 推率、DeepSeek TOP3、豆包 TOP3、Kimi TOP3、元宝 TOP3、千问 TOP3、是否需迭代优化。

**引用信源列表**

字段包括：信源标题、信源网址、信源在检测中被提及次数。

**分析报告生成**

模块包括：

每日监测报告生成、信源分析、竞品分析、舆情分析、关键词数据分析。

**已形成报告**

字段包括：报告分类、报告形成时间、下载。

报告分类与分析报告生成模块保持一致。

## 10. 资产库

资产库除客户资料、关键词、生成内容、截图证据、报告外，新增“内容生成参考文库”。

**分类资产清单**

支持通过下拉切换资产分类：

客户资料、内容参考文库、关键词、生成内容、截图证据、报告。

其中客户资料、关键词、生成内容、截图证据和报告支持“全部 / 按项目分类”切换。

## 11. 今日待办

今日待办聚合人工确认事项，包括：

待迭代关键词确认、内容审核、发布确认、风险内容处理、报告开放确认。

任务点击后在右侧处理区展示上下文、检测原因、截图证据、系统建议和操作按钮。

## 12. 总览

总览保持项目级概览，不展示关键词级检测细节。

总览中的每日检测结果按项目呈现，字段包括项目、关键词数、综合露出率、综合 TOP3 推率、低效关键词、风险。
