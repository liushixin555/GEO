# dev002. 公司管理

> 状态：✅ 已完成

---

## 功能说明

系统管理员（sysadmin）管理公司信息，包括公司的基本资料和关联的运营者、查看者。

### 公司列表

- 地址：`/company`
- 仅系统管理员可访问
- 以卡片网格形式展示所有公司
- 每张公司卡片显示：公司短名（标题）、公司全名（副标题）、地址、接口人、接口人电话
- 卡片右上角有编辑图标，点击弹出编辑表单
- 列表末尾有"添加公司"虚线卡片，点击弹出新建表单

### 公司表单（新建/编辑）

弹窗形式，包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 公司短名 | 文本输入 | 是 | 公司简称 |
| 公司全名 | 文本输入 | 是 | 公司全称 |
| 地址 | 文本输入 | 否 | 公司地址 |
| 接口人 | 文本输入 | 是 | 联系人姓名 |
| 接口人电话 | 文本输入 | 是 | 联系人电话 |
| 运营者 | 多选下拉 | 是 | 从系统中已有用户中选择，不能为空 |
| 查看者 | 多选下拉 | 否 | 从系统中已有用户中选择 |

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/companies` | sysadmin | 获取公司列表 |
| GET | `/api/companies/:id` | sysadmin | 获取公司详情（含关联用户） |
| POST | `/api/companies` | sysadmin | 创建公司 |
| PUT | `/api/companies/:id` | sysadmin | 更新公司 |

---

## 业务规则

1. **仅系统管理员可操作** — 所有公司管理 API 和页面仅 sysadmin 角色可访问
2. **公司管理 API 仅限公司管理页面使用** — 其他页面需要公司数据时必须使用 `/api/auth/companies` 系列接口
3. 每个公司至少关联一个运营者
4. 创建公司时，被关联的用户自动归属到该公司
5. 更新公司时，先解除旧的用户关联，再建立新的关联
6. 公司短名、全名、接口人、接口人电话为必填项

---
