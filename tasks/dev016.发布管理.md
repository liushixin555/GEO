# dev016. 发布管理

> 状态：✅ 已完成

---

## 功能说明

管理文章发布计划和发布状态，支持查看所有待发布文章、设置计划发布时间、同步发布平台数据。

### 发布管理列表页

- 双视图响应式展示：>=1280px 显示表格视图，<1280px 显示卡片视图
- 表格视图和卡片视图显示完全一致的信息：内容标题、关键词、项目、发布平台、内容类型、作者、计划发布时间、发布状态
- 支持搜索（标题或关键词）和状态筛选
- 显示"待计划"数量统计（橙色标签）
- 编辑计划发布时间（DatePicker + 时间选择），仅 sysadmin 和文章作者可编辑
- 发布状态自动推导：
  - 已发布（绿色）
  - 发布失败（红色）
  - 待定时发布（蓝色）— publishing 状态且已设置计划时间
  - 待计划（橙色）— publishing 状态且未设置计划时间

### 发布平台管理

- 从软盟同步发布平台数据
- 同步时读取系统配置中的软盟账号密码
- 支持搜索、分类筛选和排序
- 表格展示平台名称、分类、价格等信息

## API 接口

### 发布计划

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/publishing-schedule` | GET | 获取发布计划列表（分页） | 登录用户 |
| `/api/publishing-schedule/:id` | PUT | 更新发布计划（设置计划发布时间） | sysadmin/admin |

### 发布平台

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/publishing-platforms` | GET | 获取发布平台列表 | 登录用户 |
| `/api/publishing-platforms/sync` | POST | 从软盟同步发布平台 | sysadmin/admin |

---

## 业务规则

1. 只有 sysadmin 角色和文章作者可以编辑发布计划（之前为 sysadmin + admin，现已改为按作者匹配）
2. 只有 publishing 状态的文章可以编辑发布计划
3. 不存在的文章返回 404
4. 非 publishing 状态的文章返回 400（当前文章状态不可编辑发布计划）
5. 发布平台同步前需先配置软盟账号密码，否则返回 400
6. 文章数据按用户权限过滤（sysadmin 看全部，admin/view 看自己公司的）
