# dev016. 发布管理

> 状态：✅ 已完成

---

## 功能说明

管理文章发布计划和发布状态，支持查看所有待发布文章、设置计划发布时间、同步发布平台数据。

### 发布管理列表页

- 双视图响应式展示：>=1280px 显示表格视图，<1280px 显示卡片视图
- 表格视图和卡片视图显示完全一致的信息：内容标题、关键词、项目、发布平台、内容类型、作者、发布计划、发布状态
- 支持搜索（标题或关键词）和状态筛选
- 显示"待计划"数量统计（橙色标签）
- 编辑发布计划支持三种类型：
  1. **尽快执行**（asap）：无需选择时间，立即安排发布
  2. **指定时间执行**（scheduled）：选择具体时间点发布
  3. **指定时间之后执行**（after）：选择时间点之后发布
- 使用 Radio.Group 按钮样式选择计划类型，选择后两种时显示 DatePicker
- 仅 sysadmin 和文章作者可编辑发布计划
- **驳回功能**：sysadmin 或非创建者可驳回 publishing 状态的文章，退回 draft/manual_writing 状态
- **操作按钮图标化**：编辑计划使用 EditOutlined 图标，驳回使用 RollbackOutlined 图标，均带 Tooltip 提示
- 发布状态自动推导：
  - 已发布（绿色）
  - 发布失败（红色）
  - 尽快执行（蓝色）— publishing 状态且 schedule_type=asap
  - 定时发布（蓝色）— publishing 状态且 schedule_type=scheduled
  - 延时发布（蓝色）— publishing 状态且 schedule_type=after
  - 待计划（橙色）— publishing 状态且未设置计划类型

### 发布平台管理

- 从软盟同步发布平台数据
- 同步时读取系统配置中的软盟账号密码
- 支持搜索（按平台名称和备注模糊搜索）、分类下拉筛选（精确匹配）和服务端排序
- 排序字段：平台名称、分类、价格、收录率、发布率
- 分类下拉框支持选择和输入筛选（`showSearch`），选项从 `/publishing-platforms/taxonomies` 接口获取
- 表格展示平台名称、分类、价格等信息

## API 接口

### 发布计划

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/publishing-schedule` | GET | 获取发布计划列表（分页） | 登录用户 |
| `/api/publishing-schedule/:id` | PUT | 更新发布计划（设置计划类型和时间） | sysadmin/admin |
| `/api/publishing-schedule/:id/reject` | PUT | 驳回发布（退回修改状态） | sysadmin/admin |

### 发布平台

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/publishing-platforms` | GET | 获取发布平台列表（search=名称+备注, taxonomy=分类筛选, sortBy/sortOrder=排序） | 登录用户 |
| `/api/publishing-platforms/sync` | POST | 从软盟同步发布平台 | sysadmin/admin |
| `/api/publishing-platforms/taxonomies` | GET | 获取所有不重复分类 | sysadmin/admin |

## 业务规则

1. 只有 sysadmin 角色和文章作者可以编辑发布计划（之前为 sysadmin + admin，现已改为按作者匹配）
2. 只有 publishing 状态的文章可以编辑发布计划
3. 不存在的文章返回 404
4. 非 publishing 状态的文章返回 400（当前文章状态不可编辑发布计划）
5. 发布平台同步前需先配置软盟账号密码，否则返回 400
6. 文章数据按用户权限过滤（sysadmin 看全部，admin/view 看自己公司的）
7. **驳回规则**：只有 sysadmin 或非文章创建者可以驳回，创建者不能驳回自己的文章（职责分离）
8. **驳回目标状态**：manual_writeMode 退回 manual_writing，AI 文章退回 draft
9. **已删除文章**：发布计划列表不显示已删除的文章（deletedAt: null 过滤）

## 架构变更

### Service 层合并

发布计划功能原为独立的 `PublishingScheduleServiceImpl`，现已合并到 `ArticleServiceImpl`：

- 删除 `apis/service/publishing-schedule.service.ts`（独立接口）
- 删除 `apis/service/impl/publishing-schedule.service.impl.ts`（独立实现）
- 在 `IArticleService` 接口新增三个方法：
  - `listPublishingSchedule(params)` — 跨项目发布列表
  - `updateSchedule(id, scheduledPublishAt, scheduleType, userId, role)` — 更新发布计划
  - `rejectPublish(id, auth)` — 驳回发布
- Controller 通过 `createArticleService()` 调用，统一入口
- 状态机更新：`publishing` 状态新增 `manual_writing` 和 `draft` 转换
