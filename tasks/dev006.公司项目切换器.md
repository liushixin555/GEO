# dev006. 公司/项目切换器

> 状态：✅ 已完成

---

## 功能说明

在侧边栏底部提供公司和项目的切换功能，用户可以快速切换当前工作上下文。

### 切换器组件

- 位于侧边栏底部，显示当前公司名称和项目名称
- 点击"切换"按钮打开选择弹窗
- 弹窗中先选择公司，再选择项目
- 确认后立即生效，切换当前工作上下文

### 登录时自动选择

- 登录成功后，系统自动确定用户的公司和项目：
  - 优先恢复用户上次的选择（如果仍然有效）
  - 上次选择无效时，自动选择第一个可访问的公司和项目
  - 选择结果持久化保存到服务端，下次登录自动恢复

### 角色访问范围

| 角色 | 可访问的公司 | 可访问的项目 |
|------|-------------|-------------|
| 系统管理员 | 所有公司 | 所选公司下的所有项目 |
| 运营者 | 自己的公司 | 自己作为运营者参与的项目 |
| 查看者 | 自己的公司 | 自己作为查看者参与的项目 |

### 权限边界

- 用户没有可访问的公司 → 登录失败，提示"没有权限访问任何公司"
- 查看者没有可访问的项目 → 登录失败，提示"没有权限访问任何项目"
- 运营者没有项目 → 登录成功，项目显示为"未选择"，可前往项目管理页面创建

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/auth/companies` | 已登录 | 获取当前用户有权限的公司列表 |
| GET | `/api/auth/projects` | 已登录 | 获取当前用户在指定公司下有权限的项目列表 |
| GET | `/api/auth/context` | 已登录 | 获取当前上下文（公司+项目） |
| PUT | `/api/auth/selection` | 已登录 | 保存用户选择的公司和项目 |

---

## 业务规则

1. 用户的选择同时保存在浏览器本地和服务端数据库
2. 切换公司后，项目列表需要重新加载
3. 只有用户有权限的公司和项目才会出现在选项中
4. 侧边栏折叠时，切换器隐藏，仅显示登出按钮

---
