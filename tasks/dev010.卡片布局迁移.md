# dev010. 卡片布局

> 状态：✅ 已完成

---

## 功能说明

所有数据列表页面采用响应式双模式布局：>=1280px 显示 antd Table 表格，<1280px 显示 antd Card 卡片，卡片和表格内容保持一致。添加按钮统一放置在工具栏右侧。

## 设计规范

### 响应式布局规则

- >=1280px（桌面）：显示 antd Table 表格视图
- <1280px（平板/手机）：显示 antd Card 卡片视图
- CSS media query 控制切换：`.xxx-cards` / `.xxx-table-wrapper`
- 卡片与表格展示的数据内容保持一致

### 内容卡片

每张卡片包含：
- Card title：主标题 + extra 区域放 Tag/Switch
- Card body：antd Descriptions 组件展示字段
- Card footer：操作按钮（编辑/删除等）

### 工具栏

- 位于卡片/表格上方
- 搜索框 + 筛选下拉框 + 添加按钮（右对齐）
- 栅格总和必须 = 24，避免换行（如 sm={12} + sm={4} + sm={4} + sm={4}）

## 验收标准

- [x] 所有列表页 >=1280px 显示表格，<1280px 显示卡片
- [x] 卡片使用 antd Card + Descriptions 组件
- [x] 表格使用 antd Table 组件（非原生 HTML table）
- [x] 添加按钮在工具栏右侧靠右对齐
- [x] 栅格列宽总和 = 24
- [x] 所有样式遵循 DESIGN.md（IBM Carbon Design System）
- [x] 所有组件使用 antd，禁止原生 HTML 替代
