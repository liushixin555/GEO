# dev010. 卡片布局

> 状态：✅ 已完成

---

## 功能说明

所有数据列表页面使用卡片网格布局替代表格，提供更好的视觉效果和响应式体验。

## 设计规范

### 卡片网格布局

- 使用响应式网格：手机 1 列、平板 2 列、桌面 3-4 列
- 所有卡片等高等宽
- 卡片之间保持统一间距

### 内容卡片

每张卡片包含：
- 标题区域：主标题 + 右上角编辑图标
- 内容区域：描述性信息
- 操作区域：状态开关、标签等

### 添加按钮卡片

- 位于列表末尾
- 虚线边框样式
- 居中显示"+"图标和"添加"文字
- 与内容卡片等高

### 工具栏

- 位于卡片网格上方
- 搜索框自动填充剩余宽度
- 筛选下拉框固定宽度
- 所有控件高度统一

---

## 适用页面

| 页面 | 卡片内容 |
|------|----------|
| 用户管理 | 姓名、用户名、角色标签、状态开关 |
| 技能管理 | 技能名称、类别、描述、状态开关 |
| 公司管理 | 公司短名、全名、地址、联系人 |
| 项目管理 | 项目短名、全名、描述、运营者、查看者 |

---

## 验收标准

- [x] 所有列表页使用卡片网格，不使用表格
- [x] 响应式：手机 1 列、平板 2 列、桌面 3-4 列
- [x] 所有卡片等高
- [x] 添加按钮虚线卡片位于末尾
- [x] 工具栏控件高度一致
