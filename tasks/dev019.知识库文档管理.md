> 状态：✅ 已完成

## 功能说明

在AI知识库详情页增加"文档"页签，支持多种文档格式上传和管理。

### 文档上传功能

- 支持格式：PDF、DOC/DOCX、Markdown、JSON、YAML/YML、XLS/XLSX、CSV、PPT/PPTX、XML
- 文件大小限制：30MB
- **严格内容格式校验**（不仅仅校验后缀名）：
  - PDF：`%PDF-` 头部检测
  - DOC/XLS/PPT：OLE2 Compound Document magic bytes 检测
  - DOCX/XLSX/PPTX：ZIP 内部结构校验（`word/`/`xl/`/`ppt/` 目录）
  - Markdown：UTF-8 + Markdown 语法模式
  - JSON：JSON.parse() 验证
  - YAML：js-yaml load() 验证
  - CSV：分隔符检测（逗号、制表符、分号）
  - XML：fast-xml-parser 验证
- 伪造扩展名会被拒绝（如 `.pdf` 实际是 `.txt` 内容）

### 文档管理

- 文档卡片显示：文件类型图标、标题、文件名、文件大小、创建时间
- CRUD 操作：添加、查看、编辑标题/描述、删除
- 权限：sysadmin 可操作所有文档，普通用户只能操作自己创建的

## API 接口

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/upload/document` | POST | 上传文档（multipart/form-data） | sysadmin/admin |
| `/api/knowledge-bases/:baseId/documents` | GET | 获取文档列表 | sysadmin/admin |
| `/api/knowledge-bases/:baseId/documents/:id` | GET | 获取文档详情 | sysadmin/admin |
| `/api/knowledge-bases/:baseId/documents` | POST | 创建文档记录 | sysadmin/admin |
| `/api/knowledge-bases/:baseId/documents/:id` | PUT | 更新文档 | sysadmin/admin |
| `/api/knowledge-bases/:baseId/documents/:id` | DELETE | 删除文档 | sysadmin/admin |
| `/api/projects/:projectId/knowledge/documents` | GET | 项目维度文档聚合 | sysadmin/admin |

---

## 业务规则

1. 文档大小不超过 30MB
2. 仅支持指定格式，严格校验内容格式
3. 内容格式与扩展名不匹配时拒绝上传
4. 校验工具类封装为 `DocumentValidator`（`apis/utils/document-validator.ts`）
5. 上传失败自动清理临时文件
