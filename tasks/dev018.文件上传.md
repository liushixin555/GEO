# dev018. 文件上传

> 状态：✅ 已完成

---

## 功能说明

通用的文件上传模块，支持图片上传并返回可访问的 URL。主要用于知识库图片和文章插图的上传。

### 上传功能

- 支持 JPEG、PNG、GIF、WebP 格式图片（已移除 SVG 以防止存储型 XSS 攻击）
- 单文件最大 10MB
- 文件名使用 UUID 重命名 + MIME 映射扩展名，防止文件名冲突和扩展名注入
- 文件签名（Magic Bytes）验证，防止 MIME 类型伪造
- 上传目录：`uploads/`（项目根目录下）
- 返回文件访问路径：`/uploads/{filename}.{ext}`

### 安全措施

- **SVG 已移除**: SVG 可内嵌 JavaScript 导致存储型 XSS，已从白名单移除
- **Magic Bytes 验证**: 通过文件头签名验证实际文件类型，防止客户端伪造 MIME 类型
- **扩展名映射**: 使用 MIME→扩展名映射表，不信任客户端提供的文件扩展名
- **错误消息脱敏**: 500 错误统一返回通用消息，不泄露服务器内部信息
- **MulterError 分类**: 精确区分文件大小超限(413)、格式错误(400)等错误类型
- **验证失败文件清理**: 文件签名验证失败时自动删除已写入的临时文件

### 接口设计

- 上传接口使用 `multipart/form-data` 格式
- 字段名：`file`
- 中间件处理文件验证和存储
- 静态文件服务：Express 托管 `uploads/` 目录

## 业务规则

1. 仅允许图片格式：JPEG、PNG、GIF、WebP（不含 SVG）
2. 文件大小不超过 10MB，超限返回 413
3. 不支持的格式返回 400 错误
4. 未选择文件返回 400 错误
5. 文件内容与声明 MIME 类型不匹配返回 400 错误
6. 上传目录不存在时自动创建
7. 文件名使用 crypto.randomUUID() 保证唯一性
8. 文件扩展名由 MIME 类型映射决定，不使用客户端原始扩展名
9. 500 错误统一返回"上传失败"通用消息，不泄露内部信息
