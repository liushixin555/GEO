# dev018. 文件上传

> 状态：✅ 已完成

---

## 功能说明

通用的文件上传模块，支持图片上传和文档上传，返回可访问的 URL。主要用于知识库图片、文章插图和文档的上传。

### 图片上传

- 支持 JPEG、PNG、GIF、WebP 格式图片（已移除 SVG 以防止存储型 XSS 攻击）
- 单文件最大 10MB
- 文件名使用 UUID 重命名 + MIME 映射扩展名，防止文件名冲突和扩展名注入
- 文件签名（Magic Bytes）验证，防止 MIME 类型伪造
- 上传目录：`uploads/`（项目根目录下）
- 返回文件访问路径：`/uploads/{filename}.{ext}`

### 文档上传

- 支持 13 种文档格式：PDF、DOC、DOCX、MD、JSON、YAML、YML、XLS、XLSX、CSV、PPT、PPTX、XML
- 单文件最大 30MB
- 三层验证：扩展名白名单 → Magic Bytes 检测 → 内容深度解析
- 上传目录：`uploads/`（项目根目录下）
- 返回文件访问路径：`/uploads/{filename}.{ext}` 及原始文件名、文件类型、文件大小

### 安全措施

- **SVG 已移除**: SVG 可内嵌 JavaScript 导致存储型 XSS，已从白名单移除
- **Magic Bytes 验证**: 通过文件头签名验证实际文件类型，防止客户端伪造 MIME 类型
- **扩展名映射**: 使用 MIME→扩展名映射表，不信任客户端提供的文件扩展名
- **错误消息脱敏**: 500 错误统一返回通用消息，不泄露服务器内部信息
- **MulterError 分类**: 精确区分文件大小超限(400)、格式错误(400)等错误类型
- **验证失败文件清理**: 文件签名验证失败时自动删除已写入的临时文件
- **YAML 安全解析**: 使用 `JSON_SCHEMA` 禁止 JS 特定类型，防止反序列化 RCE
- **XML 安全解析**: 显式禁用外部实体和 HTML 实体，防止 XXE 攻击
- **ZIP 炸弹防护**: 限制 ZIP 条目数和解压后总大小
- **Markdown 严格验证**: 必须包含 Markdown 语法模式，不允许任意文本绕过
- **文件名长度限制**: 最大 255 个字符
- **扩展名防御性检查**: 扩展名中不允许包含路径分隔符

### 接口设计

- 上传接口使用 `multipart/form-data` 格式
- 字段名：`file`
- 中间件处理文件验证和存储
- 静态文件服务：Express 托管 `uploads/` 目录
- 异步 I/O：使用 `fs/promises` 避免阻塞事件循环

---

## 业务规则

1. 图片仅允许：JPEG、PNG、GIF、WebP（不含 SVG）
2. 文档允许 13 种格式：PDF、DOC、DOCX、MD、JSON、YAML、YML、XLS、XLSX、CSV、PPT、PPTX、XML
3. 图片大小不超过 10MB，文档大小不超过 30MB，超限返回 400
4. 不支持的格式返回 400 错误
5. 未选择文件返回 400 错误
6. 文件内容与声明格式不匹配返回 400 错误
7. 上传目录不存在时自动创建
8. 文件名使用 crypto.randomUUID() 保证唯一性
9. 500 错误统一返回"上传失败"通用消息，不泄露内部信息
10. 文件名长度不超过 255 个字符
11. 扩展名不允许包含路径分隔符（/、\、..）
