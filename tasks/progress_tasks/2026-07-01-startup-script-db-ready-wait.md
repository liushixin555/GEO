# 2026-07-01 一键启动脚本等待数据库就绪

## 背景

桌面一键启动脚本启动项目后，用户在登录页使用 `123 / 123` 登录时偶发显示“用户名或密码错误”。排查发现账号本身有效，但脚本启动后 PostgreSQL 仍处于启动/恢复阶段，后端认证接口捕获到底层数据库异常后统一返回 401，前端因此显示用户名或密码错误。

## 变更

- `启动项目.bat` 新增 `pg_isready` 等待逻辑，确认 PostgreSQL 5432 可用后再继续。
- 后端启动后新增 `/api/health` 等待逻辑，确认 8080 健康检查通过后再启动/打开前端。
- 保留源码模式启动：后端 `npm.cmd run dev:api`，前端 `npm.cmd run dev:page`。

## 验证

- `http://localhost:3000` 返回 200。
- `http://localhost:8080/api/health` 返回 200，内容为 `{"status":"ok"}`。
- `POST /api/v1/auth/login` 使用 `123 / 123` 返回登录成功。
