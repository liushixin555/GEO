# fix062: CORS跨域拒绝返回403+前端强制退出登录+antd Card bordered废弃警告+MaskReveal残留导出清理

**日期**: 2026-05-27
**分支**: dev2
**commit**: 012e66d

## 问题描述

1. 后端CORS拒绝origin时使用`callback(null, false)`——请求仍继续执行（浪费资源），前端无任何反馈
2. `.env` CORS_ORIGINS缺少`http://localhost:3000`（Vite实际端口），导致本地开发被误拒
3. antd Card组件`bordered`属性在antd 6.x已废弃，应改为`variant="outlined"`
4. `pages/components/index.ts`导出不存在的MaskReveal组件，导致TypeScript编译失败

## 修复内容

### 后端 (`apis/app.ts`)
- CORS拒绝时改为`callback(new Error('CORS origin not allowed'))`，请求立即中断
- 全局错误处理器捕获CORS错误，返回403 `{ code: 403, message: '跨域请求被拒绝' }`
- CORS日志改为结构化JSON（含origin和allowedOrigins），方便排查

### 前端 (`pages/lib/apiClient.ts`)
- 拦截403+跨域消息：清除localStorage全部auth数据，跳转登录页
- 拦截网络错误（浏览器CORS拦截）：同上处理
- 401处理补全清除selected_company/selected_project
- 返回`new Promise(() => {})`阻止后续代码执行

### 配置 (`.env`)
- CORS_ORIGINS添加`http://localhost:3000`（Vite config实际端口）

### antd废弃修复
- `pages/login/index.tsx`: Card `bordered` → `variant="outlined"`
- `pages/swagger/index.tsx`: Card `bordered` → `variant="outlined"`

### 残留清理
- `pages/components/index.ts`: 删除不存在的MaskReveal导出
