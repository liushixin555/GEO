# dev020. 知识库UI优化

> 状态：✅ 已完成

---

## 功能说明

对AI知识库模块进行多项UI优化，包括页签顺序调整、响应式布局、操作按钮统一风格等。

### 变更内容

1. **关键词页签顺序调整**
   - tab 顺序从 `关键词→画像→图片→文档` 调整为 `文档→画像→图片→关键词`
   - 默认 active tab 改为 `文档`
   - 知识库列表页统计显示顺序同步调整
   - 知识清单统计卡片和筛选器顺序同步调整

2. **知识库详情页响应式布局**
   - 4个页签（文档/画像/图片/关键词）均支持响应式卡片/表格切换
   - 宽屏 >=1280px 显示 Table 表格视图
   - 窄屏 <1280px 显示卡片视图
   - 添加按钮统一放到 toolbar 中

3. **操作按钮统一为纯 icon**
   - 所有页面的编辑/删除/下载/查看按钮统一为纯 icon
   - 禁止 icon+文字 或纯文字按钮
   - 无权限时按钮始终显示但 disabled（禁止点击）

4. **图片/文档重复校验**
   - 图片创建/更新时校验标题和 URL 重复
   - 文档创建/更新时校验标题和文件 URL 重复
