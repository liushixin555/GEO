# dev012. LLM 模型管理

> 状态：✅ 已完成

---

## 功能说明

管理系统中可用的 LLM（大语言模型）配置，供 AI 知识库和 GEO 文章等功能调用。仅系统管理员可管理。

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/llm-models` | sysadmin | 获取模型列表 |
| GET | `/api/llm-models/enabled` | sysadmin, admin | 获取启用的模型列表 |
| GET | `/api/llm-models/:id` | sysadmin | 获取模型详情 |
| POST | `/api/llm-models` | sysadmin | 创建模型 |
| PUT | `/api/llm-models/:id` | sysadmin | 更新模型 |
| DELETE | `/api/llm-models/:id` | sysadmin | 删除模型 |

---

## 业务规则

1. **仅系统管理员可操作** — 其他角色访问返回 403（listEnabled 允许 admin）
2. 每个模型包含：供应商、API 地址、API 密钥、模型名称、启用状态
3. 模型名称不可重复
4. **输入验证** — 创建和更新均进行字段类型检查、非空检查、长度限制
5. **SSRF 防护** — Base URL 禁止指向内网地址（localhost、127.x、10.x、172.16-31.x、192.168.x、169.254.x）
6. **ID 解析安全** — 拒绝 0、负数、浮点数、前导零等非法 ID
