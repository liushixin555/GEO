# dev008. 前端组件库迁移

> 状态：✅ 已完成

---

## 功能说明

将前端 UI 组件库从 element-react 统一迁移到 Ant Design (antd)，同时遵循 IBM Carbon Design System 设计规范。

## 设计规范

- **主题色**：IBM Carbon Blue `#0f62fe`
- **圆角**：全局直角（0px），符合 Carbon 风格
- **字体**：IBM Plex Sans，本地打包，不使用外部 CDN
- **控件高度**：统一 40px（按钮、输入框、下拉选择器）
- **开关控件**：保持椭圆胶囊样式，不受全局直角规则影响

## 组件使用规范

- 所有 UI 元素必须使用 antd 组件（按钮、输入框、表单、弹窗、下拉、开关、标签、菜单、布局等）
- **禁止使用 antd 表格（Table）组件** — 数据列表统一使用卡片网格布局
- 弹窗使用 Modal 组件
- 列表分页使用 Pagination 组件
- 加载状态使用 Spin 组件
- 间距使用 Space 组件

## 样式规范

- 唯一全局样式文件：`pages/styles/global.css`
- **禁止在页面文件中使用行内样式**
- 通过 CSS 变量 + antd 主题覆盖实现 Carbon Design 规范
- 所有新增样式必须使用语义化 CSS 类名
