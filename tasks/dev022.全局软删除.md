# dev022. 全局软删除

> 状态：✅ 已完成

---

## 功能说明

将所有硬删除改为软删除，删除时只标记 `deletedAt` 字段，不实际删除数据库记录。前端通过后端过滤不显示已删除数据。

### 变更内容

1. **Schema 变更** — 所有18个模型添加 `deletedAt DateTime?` 字段
2. **删除逻辑** — 所有 `delete()` / `deleteMany()` 改为 `update()` / `updateMany()` 设置 `deletedAt`
3. **查询过滤** — 所有 `findMany` / `findFirst` / `$queryRaw` 查询添加 `deletedAt: null` 过滤
4. **重复检查** — 标题/URL重复检查也过滤已删除记录

### 涉及模型

Company, User, Skills, LlmModel, PublishingPlatform, SystemConfig, Project, ProjectOperator, ProjectViewer, KnowledgeBase, Article, ArticleVersion, KnowledgeKeyword, KeywordExpandedWord, MinedKeyword, KnowledgePortrait, KnowledgeImage, KnowledgeDocument
