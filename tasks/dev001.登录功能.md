# dev001. 登录功能

> 状态：✅ 已完成

---

## 功能说明

用户通过用户名和密码登录系统，获取访问令牌后进入主界面。

### 登录页面

- 提供用户名输入框和密码输入框
- 点击"登录"按钮提交
- 登录失败时显示错误提示（用户名或密码错误、无权限等）

### 登录后跳转

- 未登录时访问任何受保护页面 → 自动跳转到登录页，并记住原始访问路径
- 如果原始访问不涉及页面地址，仅仅是网站地址，登录成功后跳转：sysadmin角色→公司设置，admin角色→GEO文章，view角色→GEO成绩
- 如果原始访问涉及页面地址，登录成功后 → 自动跳回原始访问路径，如果原地址用户没权限，则跳转：sysadmin角色→公司设置，admin角色→GEO文章，view角色→GEO成绩

### 登录接口

- 地址：`POST /api/auth/login`
- 此接口为公开接口，无需认证
- 提交参数：用户名、密码
- 返回内容：访问令牌 + 用户基本信息（用户名、姓名、角色）
- 令牌有效期：2 小时（可配置）

### 令牌验证

- 地址：`GET /api/auth/verify`
- 需要登录后访问
- 前端每次加载页面时调用，验证令牌是否仍有效

### 登出

- 地址：`POST /api/auth/logout`
- 需要登录后访问
- 清除前端存储的令牌和用户信息，跳转到登录页

---

## 业务规则

1. 用户名和密码都不能为空，否则提示错误
2. 密码加密存储，登录时密文比对
3. 登录成功后，令牌和用户信息存储在浏览器本地
4. 后续所有 API 请求在请求头中携带令牌
5. 令牌过期后，前端自动跳转到登录页

---

## 验收标准

- [x] 输入正确的用户名和密码可以成功登录
- [x] 输入错误的用户名或密码提示错误
- [x] 用户名或密码为空时提示不能为空
- [x] 登录成功后根据角色跳转到不同默认页面：sysadmin角色→公司设置，admin角色→GEO文章，view角色→GEO成绩
- [x] 未登录访问受保护页面时跳转到登录页
- [x] 登录后自动跳回之前想访问的页面
- [x] 已登录状态访问登录页自动跳转走
