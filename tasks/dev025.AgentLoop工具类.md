## 功能说明

基于 deepagents + langchain 实现 ReAct 风格的 Agent Loop 工具类，替换原有 axios 直接调用大模型的方式。

### 核心模块

- `apis/utils/llm.utils/agent-loop.util.ts` — Agent Loop 工具类
- `apis/utils/llm.utils/index.ts` — barrel 导出

### API

```ts
AgentLoopUtil.run(options: AgentLoopOptions): Promise<AgentLoopResult>
```

**输入** (`AgentLoopOptions`):

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| baseUrl | string | 是 | OpenAI 兼容 API 的 Base URL |
| apiKey | string | 是 | API Key |
| modelName | string | 是 | 模型名称（如 gpt-4o、deepseek-chat） |
| prompt | string | 是 | 用户提示词 |
| systemPrompt | string | 否 | 系统提示词 |
| skills | string[] | 否 | 技能子目录名列表（如 ['ant-design']） |
| skillsBaseDir | string | 否 | 技能文件根目录绝对路径（配合 skills 使用） |
| temperature | number | 否 | 生成温度（默认 0） |

**输出** (`AgentLoopResult`):

| 字段 | 类型 | 说明 |
|------|------|------|
| content | string | Agent 最终回复文本 |
| iterations | number | 推理迭代次数 |
| toolCalls | ToolCallRecord[] | 全部工具调用记录 |

### 内置工具

由 deepagents 默认 middleware 提供（不传 middleware 参数）：

| 工具 | middleware | 功能 |
|------|-----------|------|
| ls / read_file / write_file / edit_file / glob / grep | filesystemMiddleware | 文件系统操作 |
| write_todos | todoListMiddleware | 任务规划与进度跟踪 |
| task | subAgentMiddleware | 子代理任务委派 |
| 上下文自动摘要 | summarizationMiddleware | 长文本场景自动压缩 |

### 技能集成

- 调用方传入 `skills`（子目录名列表）+ `skillsBaseDir`（根目录绝对路径）
- `AgentLoopUtil` 自动创建 `FilesystemBackend` 指向 `skillsBaseDir`
- deepagents 从磁盘加载 `SKILL.md` 注入 Agent 上下文

## 集成点

### generateArticle 重构

`apis/service/impl/llm.service.impl.ts` 的 `generateArticle` 方法：
- **之前**: 直接 `axios.post` 调用大模型 HTTP API
- **之后**: 调用 `AgentLoopUtil.run()` 走 deepagents agent loop
- 解析 `params.skills` 技能名称 → 查 `Skills` 表获取 `skillDir` → 构建 POSIX 路径传入
