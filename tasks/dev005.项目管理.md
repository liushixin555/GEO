# dev005. 项目管理

> 状态：✅ 已完成

---

## 功能说明

管理公司下的项目，每个项目可指定多个运营者和多个查看者。系统管理员可管理所有项目，运营者只能管理自己有权限的项目，或在有权限的公司下新增项目。

### 项目列表

- 地址：`/project`
- 系统管理员和运营者可访问
- 以卡片网格形式展示项目
- 支持搜索、按公司筛选、按状态筛选（启用/禁用）
- 分页展示
- 每张项目卡片显示：项目短名、项目全名、描述、所属公司名、运营者、查看者、状态
- 卡片右上角有编辑图标，点击弹出编辑表单
- 列表末尾有"添加项目"虚线卡片

### 项目表单（新建/编辑）

弹窗形式，包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 项目短名 | 文本输入 | 是 | 项目简称 |
| 项目全名 | 文本输入 | 是 | 项目全称 |
| 项目描述 | 文本输入 | 否 | 项目说明 |
| 所属公司 | 下拉选择 | 是 | 选择公司后联动加载该公司的用户 |
| 项目运营者 | 多选下拉 | 否 | 从所选公司的运营者用户中选择 |
| 项目查看者 | 多选下拉 | 否 | 从所选公司的查看者用户中选择 |

**联动规则**：新建时切换所属公司会自动清空已选的运营者和查看者，并重新加载新公司的用户列表。

**编辑限制**：编辑项目时，所属公司字段不可修改。

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/projects` | sysadmin + admin | 获取项目列表 |
| GET | `/api/projects/:id` | sysadmin + admin | 获取项目详情 |
| POST | `/api/projects` | sysadmin + admin | 创建项目 |
| PUT | `/api/projects/:id` | sysadmin + admin | 更新项目 |
| DELETE | `/api/projects/:id` | sysadmin + admin | 删除项目 |

---

## 业务规则

1. **权限隔离**：
   - 系统管理员可管理所有公司的项目
   - 运营者只能管理自己有权限的项目
   - 运营者只能在自己有权限的公司下新增项目
   - 运营者不能将项目转移到无权限的公司
2. **运营者/查看者归属**：
   - 创建或更新项目时，运营者和查看者必须属于所选公司
   - 如果选了不属于该公司的用户，返回错误提示
3. **所属公司不可变**：项目一旦创建，所属公司不可更改
4. 项目短名、项目全名、所属公司为必填项
