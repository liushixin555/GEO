# dev021. 关键词一分三

> 状态：✅ 已完成

---

## 功能说明

将知识库详情页关键词 tab 的"添加关键词"按钮拆分为三个独立功能按钮。

### 三个按钮

1. **关键词挖掘** — 新页面，从文档/画像/图片中通过 LLM 提取关键词
   - 支持选择挖掘来源（全部/文档/画像/图片）
   - 提取的关键词持久化保存，下次进入可直接选择
   - 支持全选/反选，多选后保存到知识库
   - 可多次挖掘叠加关键词
2. **智能扩词** — 保持原有逻辑，跳转到 KeywordDetail 页面
3. **手工输入** — Modal 弹窗，支持换行/逗号/分号分隔批量输入

### 关键词挖掘页面

- Breadcrumb: AI知识库 > 知识库名称 > 关键词挖掘
- 来源选择 Radio.Group
- 挖掘按钮 + 清空候选按钮
- Table 多选列表（全选/反选/单选/单个移除）
- 底部保存栏

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/knowledge-bases/:baseId/mined-keywords` | GET | 获取已挖掘关键词列表 |
| `/api/knowledge-bases/:baseId/keywords/mine` | POST | 触发关键词挖掘 |
| `/api/knowledge-bases/:baseId/mined-keywords/save` | POST | 保存选中关键词到知识库 |
| `/api/knowledge-bases/:baseId/mined-keywords/batch-toggle` | PUT | 批量切换选中状态 |
| `/api/knowledge-bases/:baseId/mined-keywords` | DELETE | 清空候选关键词 |

## 数据模型变更

新增 `mined_keywords` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Int PK | 自增主键 |
| base_id | Int FK | 关联知识库 |
| keyword | VARCHAR(200) | 关键词文本 |
| selected | Boolean | 是否选中 |
| created_by | Int? | 创建者 |
| created_at | Timestamptz | 创建时间 |

唯一约束：(base_id, keyword)
