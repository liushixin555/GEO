# dev014. GEO文章

> 状态：✅ 已完成（安全加固）

---

## 功能说明

管理项目下的GEO文章。每篇文章归属于一个项目，具有完整的生命周期状态流转（草稿→AI生成→审核→发布），支持AI知识库关键词/画像/图片关联，以及多平台发布。

### 文章列表

- 地址：`/project/:projectId/articles`
- 系统管理员和运营者可访问，运营者需有当前项目的权限
- 以卡片网格形式展示文章
- 双视图响应式展示：>=1280px 显示表格视图（antd Table），<1280px 显示卡片视图（antd Card + Descriptions）
- 表格视图和卡片视图显示完全一致的信息：标题、关键词、状态、创建时间、操作
- 支持搜索（按文章标题）、按状态筛选
- 分页展示

### 文章表单（新建/编辑）

独立路由页面形式（非弹窗），包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 文章标题 | 文本输入 | 是 | 文章标题 |
| 文章关键词 | 多选标签 | 否 | 可输入可选择，选择源来自AI知识库的关键词 |
| 文章画像 | 文本域/选择 | 否 | 可输入可选择，选择源来自AI知识库的画像，输入/选择可切换，输入框根据内容自动增高 |
| 文章插图 | 多选 | 否 | 可上传可选择，选择源来自AI知识库的图片，上传也是自动上传为AI知识库的图片，然后自动选中为文章插图 |
| 发布平台 | 多选下拉 | 否 | 只能选择，选择源来自发布平台数据表 |

### 文章详情/编辑页面

- 独立路由页面（`/article/:id`），非弹窗
- 包含 Tab 标签页切换：「文章设置」和「正文」
- **文章设置 Tab**：展示文章标题、关键词、画像、插图、发布平台等字段，可编辑状态下可修改
- **正文 Tab**：
  - 仅在文章 content 不为 null 且不为空时显示
  - 展示当前版本号（如 v1.0、v2.0）
  - 支持正文内容编辑和保存
  - 每次保存正文，自动递增版本号（1.0 → 2.0 → 3.0 …），并保存版本历史
  - 在文章处于**待审核**状态时，文章创建者仍可手工编辑正文
- 非可编辑状态时，表单字段为只读（disabled）

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/projects/:projectId/articles` | sysadmin + admin（需项目权限） | 获取项目下的文章列表 |
| GET | `/api/projects/:projectId/articles/:id` | sysadmin + admin（需项目权限） | 获取文章详情 |
| POST | `/api/projects/:projectId/articles` | sysadmin + admin（需项目权限） | 创建文章 |
| PUT | `/api/projects/:projectId/articles/:id` | sysadmin + 创建者 | 更新文章 |
| DELETE | `/api/projects/:projectId/articles/:id` | sysadmin + 创建者（仅草稿状态） | 删除文章 |
| PUT | `/api/projects/:projectId/articles/:id/review` | sysadmin + admin（需项目权限） | 审核文章（通过/不通过） |
| PUT | `/api/projects/:projectId/articles/:id/content` | sysadmin + 创建者 | 更新文章正文（支持待审核状态编辑） |
| GET | `/api/projects/:projectId/articles/:id/versions` | sysadmin + admin（需项目权限） | 获取文章正文版本历史 |

## 状态流转

```
草稿 ──(保存并提交)──→ AI生成中
AI生成中 ──(成功)──→ 待审核
AI生成中 ──(失败)──→ AI生成失败
AI生成失败 ──(编辑后提交)──→ AI生成中
待审核 ──(审核通过)──→ 发布中
待审核 ──(审核不通过)──→ 草稿
发布中 ──(成功)──→ 发布成功
发布中 ──(失败)──→ 发布失败
发布失败 ──(编辑后提交)──→ AI生成中
```

各状态下的用户操作权限：

| 状态 | 查看 | 编辑 | 其他操作 |
|------|------|------|----------|
| 草稿 | 有权限用户 | 创建者/sysadmin | 可删除 |
| AI生成中 | 有权限用户 | — | — |
| AI生成失败 | 有权限用户 | 创建者/sysadmin | 编辑后重新提交，回到AI生成中 |
| 待审核 | 有权限用户 | 创建者可编辑正文 | 审核通过→发布中；审核不通过→草稿 |
| 发布中 | 有权限用户 | — | — |
| 发布失败 | 有权限用户 | 创建者/sysadmin | 编辑后重新提交，回到AI生成中 |
| 发布成功 | 有权限用户 | — | — |

## 业务规则

1. **权限隔离**：
   - 系统管理员可查看和操作所有项目的文章
   - 运营者只能查看和操作自己有权限的项目下的文章
   - 运营者访问无权限的项目文章时返回 403 错误
2. **编辑权限**：
   - 仅文章创建者和sysadmin角色可编辑文章
   - 编辑仅在草稿、AI生成失败、发布失败状态下可用
   - 编辑后提交，文章回到AI生成中状态
3. **查看权限**：
   - sysadmin可查看所有文章
   - 当前项目的所有运营者（有项目权限的admin用户）可查看该项目下的文章
4. **删除限制**：
   - 仅草稿状态下可删除文章
   - 仅文章创建者和sysadmin可删除
5. **审核操作**：
   - 待审核状态的文章，有项目权限的用户可进行审核
   - 审核通过→进入发布中
   - 审核不通过→回到草稿状态
   - **创建者不能审核自己的文章**（职责分离 SoD 原则，sysadmin 除外）
6. **创建者记录**：创建文章时系统自动记录创建者身份
7. **文章标题**为必填项
8. **文章正文版本管理**：
   - 文章 content 字段存储当前正文内容
   - 每次保存正文，版本号自动递增（1.0 → 2.0 → 3.0 …）
   - 每个版本的历史内容保存在 article_versions 表中
   - 版本号规则：整数递增，显示为 x.0 格式
9. **待审核状态正文编辑**：
   - 文章处于待审核（pending_review）状态时，创建者仍可编辑正文内容
   - 通过专用 API 端点 `PUT .../content` 更新，不影响文章设置字段的编辑权限
10. **文章页面为独立路由**：
    - 列表页：`/article`
    - 新建/编辑/查看：`/article/:id`（id 为 `new` 或数字）
    - 使用 Tab 标签页切换「文章设置」和「正文」
    - 非编辑状态时表单字段为只读
11. **手工编写模式文档导入**：
    - 选择「手工编写」后，标题 Form.Item 的 label 旁显示「导入」按钮
    - 支持 `.md`、`.doc`、`.docx` 格式
    - 解析逻辑：
      - `.md`：直接读取文本，提取 `# 一级标题` 作为标题，剩余内容作为正文
      - `.doc/.docx`：通过 mammoth 转 HTML，再将 h1/h2/h3/p 转为 markdown 格式
    - 填充规则：
      - 有 `# 一级标题` → 自动填充文章标题，并从正文中移除该标题
      - 无一级标题 → 不填充标题（不报错），仅填充正文
    - 正文始终自动填充
12. **文章标题显示**：标题为 null 或空时，列表和详情显示"待生成"
