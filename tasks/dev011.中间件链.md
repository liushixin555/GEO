# dev011. 中间件链

> 状态：✅ 已完成

---

## 功能说明

所有 API 请求（除登录接口）必须依次通过安全中间件链的校验，确保系统安全。

## 中间件执行顺序

```
请求 → 反爬虫 → 限流 → JWT认证 → 角色校验 → 业务处理
```

### 反爬虫校验

- 校验请求中的 User-Agent 信息
- User-Agent 必须至少 10 个字符，否则拒绝访问
- 同一 IP 地址每分钟超过 200 次请求，自动封禁 10 分钟

### 限流控制

- 基于 IP 地址限制请求频率
- 超出限制时返回 429 状态码，提示"请求过于频繁，请稍后再试"
- 时间窗口和最大请求数可通过配置文件调整

### JWT 认证

- 从请求头的 Authorization 字段提取访问令牌
- 验证令牌的合法性和有效期
- 无效或过期时返回 401 状态码
- 唯一例外：登录接口不需要认证

### 角色校验

- 每个接口指定允许访问的角色列表
- 用户角色不在列表中时返回 403 状态码
- 角色列表在路由注册时配置

---

## 验收标准

- [x] 无 User-Agent 的请求被拒绝
- [x] 超频请求被限流
- [x] 无令牌的请求返回 401
- [x] 令牌过期的请求返回 401
- [x] 角色不符的请求返回 403
- [x] 登录接口不受认证限制
