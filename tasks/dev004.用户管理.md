# dev004. 用户管理

> 状态：✅ 已完成

## 功能说明

管理系统用户账号。仅系统管理员可访问。

### 用户列表

- 地址：`/users`
- 仅系统管理员可访问
- 以卡片网格形式展示用户
- 支持搜索（按用户名或姓名）、按角色筛选、按状态筛选（启用/禁用）
- 分页展示
- 每张用户卡片显示：姓名、用户名、角色标签、启用/禁用状态开关
- 卡片右上角有编辑图标，点击弹出编辑表单
- 列表末尾有"添加用户"虚线卡片
- 不提供删除功能，通过启用/禁用开关管理用户状态

### 用户表单（新建/编辑）

弹窗形式，包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用户名 | 文本输入 | 是（仅新建） | 登录账号，不可重复 |
| 密码 | 密码输入 | 是（仅新建） | 登录密码 |
| 姓名 | 文本输入 | 是 | 用户中文名 |
| 角色 | 下拉选择 | 是 | 系统管理员 / 运营者 / 查看者 |

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/users` | sysadmin | 获取用户列表（分页、搜索、筛选） |
| GET | `/api/users/:id` | sysadmin | 获取用户详情 |
| POST | `/api/users` | sysadmin | 创建用户 |
| PUT | `/api/users/:id` | sysadmin | 更新用户 |
| DELETE | `/api/users/:id` | sysadmin | 删除用户 |

---

## 业务规则

1. **仅系统管理员可操作** — 运营者和查看者访问用户管理 API 均返回 403
2. **用户不绑定单一公司** — 一个用户可能关联多家公司的多个项目，具体权限通过公司关联设置
3. **系统管理员账号受保护**：
   - 系统管理员的角色不可被修改
   - 系统管理员账号不可被删除
4. 用户名必须唯一，重复时返回冲突错误
5. 密码加密存储
