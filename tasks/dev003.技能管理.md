# dev003. 技能管理

> 状态：✅ 已完成

---

## 功能说明

管理系统中的技能库。技能不属于任何公司和项目，是全局共享资源。通过上传 zip 包（含 SKILL.md）创建技能，系统自动从 SKILL.md 的 frontmatter 中提取名称和描述。

### 技能列表

- 地址：`/skills`
- 系统管理员和运营者可访问
- 双视图响应式展示：>=1280px 显示表格视图（antd Table），<1280px 显示卡片视图（antd Card）
- 表格列：技能名称、描述、添加者、添加时间、操作（删除）
- 卡片视图：名称为卡片标题，描述独占一行（最多5行省略），添加者和添加时间显示在底部元数据行
- 支持搜索（按技能名称）
- 分页展示

### 技能上传（创建）

- 点击「添加技能」按钮弹出上传 Modal
- 上传包含 SKILL.md 的 zip 包
- 支持格式：`.zip`
- 后端解析流程：
  1. 保存 zip 到临时目录
  2. 解析 SKILL.md 获取技能名称和描述（不提取文件）
  3. 查询数据库是否存在**未删除**的同名技能 → 若存在立即返回 409 错误
  4. 查询数据库是否存在**已删除**的同名技能 → 用于判断是否复用记录
  5. 解压到 `skills/{目录名}/`（已确认无活跃重复，始终允许覆盖残留目录）
  6. 校验 SKILL.md 存在且 frontmatter 格式正确（必须有 `name` 字段）
  7. **同名规则铁律**：
     - 如果存在**未删除**的同名技能 → 报错「已存在同名技能」，上传失败
     - 如果存在**已删除**的同名技能 → 上传成功，用新数据刷新数据库记录（description、skillDir、createdBy），并将 deletedAt 设为 null
     - 如果不存在同名技能 → 创建新记录
  8. 写入数据库记录

### SKILL.md 格式要求

```markdown
---
name: 技能名称
description: 技能描述
---

# 技能标题

技能正文内容...
```

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/skills` | sysadmin + admin | 获取技能列表（分页、搜索） |
| GET | `/api/skills/:id` | sysadmin + admin | 获取技能详情 |
| POST | `/api/skills` | sysadmin + admin | 上传 zip 包创建技能（multipart/form-data） |
| PUT | `/api/skills/:id` | sysadmin + 创建者 | 更新技能 |
| DELETE | `/api/skills/:id` | sysadmin + 创建者 | 删除技能（同时删除技能目录） |

## 业务规则

1. **技能不属于任何公司和项目** — 技能是全局资源，无公司归属
2. **系统管理员（sysadmin）**：可以查看、上传、删除所有技能，无限制
3. **运营者（admin）**：
   - 可以查看所有技能
   - 可以上传新技能，上传时系统自动记录创建者
   - 只能删除**自己上传的技能**
   - 尝试删除他人技能时返回 403 错误
4. 技能名称唯一，不允许重复（活跃记录）
5. 删除技能时同时删除 `skills/` 下对应的目录（软删除数据库记录 + 硬删除文件）
6. 已删除的同名技能重新上传时，复用原数据库记录刷新数据并恢复为未删除状态
7. 无禁用/启用功能
