# dev003. 技能管理

> 状态：✅ 已完成

---

## 功能说明

管理系统中的技能库。技能不属于任何公司和项目，是全局共享资源。

### 技能列表

- 地址：`/skills`
- 系统管理员和运营者可访问
- 以卡片网格形式展示技能
- 支持搜索（按技能名称）、按类别筛选、按状态筛选（启用/禁用）
- 分页展示
- 每张技能卡片显示：技能名称、类别、描述
- 卡片上有开关控件控制启用/禁用状态
- 卡片右上角有编辑图标，点击弹出编辑表单
- 列表末尾有"添加技能"虚线卡片

### 技能表单（新建/编辑）

弹窗形式，包含以下字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 技能名称 | 文本输入 | 是 | 技能的名称 |
| 类别 | 文本输入 | 是 | 技能所属类别 |
| 描述 | 文本输入 | 否 | 技能的详细说明 |

### API 端点

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/skills` | sysadmin + admin | 获取技能列表（分页、搜索、筛选） |
| GET | `/api/skills/:id` | sysadmin + admin | 获取技能详情 |
| POST | `/api/skills` | sysadmin + admin | 创建技能 |
| PUT | `/api/skills/:id` | sysadmin + admin | 更新技能 |
| DELETE | `/api/skills/:id` | sysadmin + admin | 删除技能 |

---

## 业务规则

1. **技能不属于任何公司和项目** — 技能是全局资源，没有公司归属
2. **系统管理员（sysadmin）**：可以增删改查所有技能，无限制
3. **运营者（admin）**：
   - 可以查看所有技能（无过滤）
   - 可以创建新技能，创建时系统自动记录创建者
   - 只能修改和删除**自己创建的技能**
   - 尝试修改或删除他人创建的技能时返回 403 错误
4. 技能名称和类别为必填项
5. 创建技能时系统自动记录创建者身份，无需用户手动填写
