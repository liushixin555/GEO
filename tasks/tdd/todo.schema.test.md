## 测试覆盖维度
1. **正向验证**：所有合法值和边界值（min/max 边界）
2. **负向验证**：非法类型、越界值、空值、null、undefined
3. **边界值测试**：max/min 边界的 +1/-1 测试
4. **类型强制转换**：z.coerce.number() 的字符串→数字、布尔值→数字行为
5. **枚举验证**：tab 和 priority 的枚举值（正向+无效值+大小写敏感）
6. **nullable 字段**：project_id/object_id/due_at 的 null 接受行为
7. **optional 字段**：source/priority/due_at/remark/action 的 optional 行为
8. **默认值**：page/pageSize/tab 的 default 行为
9. **类型安全**：数字/字符串/布尔值/null/数组/对象的类型拒绝
10. **非 strict 模式**：Zod 默认 strip 未知字段行为
11. **unicode 支持**：中文字符和 emoji 的正确处理

## 发现的 Schema 行为特征
1. **z.coerce 布尔值转换**：`z.coerce.number()` 会将 `true` 转为 `1`（`Number(true)===1`），将 `false` 转为 `0`（`Number(false)===0`）。因此 `page: true` 会通过校验变成 `page: 1`，而 `page: false` 会因 `min(1)` 被拒绝。
2. **非 strict 模式**：所有 schema 均未调用 `.strict()`，未知字段不报错但被 strip。
3. **priority 字段无枚举约束**：`createTodoSchema` 和 `updateTodoSchema` 的 `priority` 是 `z.string().optional()`，不限制枚举值（不同于 `listTodosSchema` 的 `z.enum(['P0','P1','P2','P3'])`），可以传入任意字符串。
