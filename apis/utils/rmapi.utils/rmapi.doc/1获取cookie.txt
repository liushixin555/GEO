-接口地址 https://rmapi.ruan.net/api/auth/authenticate
-请求方法 post
输入参数
```
mobile=登录账号
password=登录密码
identity=advertiser
captcha_token=advertiser
captcha=advertiser
api_key=your_ruanmeng_api_key
```
**注意：token接口只用获取一次，并且全局有效。其他接口，如果返回status=401之后，需要重新获取token**

返回说明
```
{
    "success": true,
    "message": "验证成功",
    "data": {
        "token": "your_ruanmeng_token"
    },
    "status": 200
}
```
